### 💻 Tech Stack & Skills

**Frontend & Mobile Development**
- **Frameworks & Libraries:** React, Next.js (App Router), React Native, Vue.js, Angular, Ionic.
- **Languages:** TypeScript, JavaScript, HTML5, CSS3.
- **Styling & UI:** Tailwind CSS, Framer Motion, Bootstrap, Once UI.
- **Concepts:** Progressive Web Apps (PWA), Responsive Design, State Management.

**Backend & Architecture**
- **Core:** Node.js, Express, Kotlin, Java, PHP, C/C++.
- **Architecture:** REST APIs, Microservices, Automatic Failover Systems.
- **Databases:** MongoDB (Atlas & Compass), MySQL, Firebase, Oracle DB.

**Infrastructure, Tools & Security**
- **Deployment & Cloud:** Vercel, Cloudflare Tunnels, Virtual Machines.
- **Tools:** Git/GitHub, Electron, SheetJS, Nodemailer, Prisma ORM.
- **Security & Auth:** Clerk Authentication, Content Security Policy (CSP), Data Sanitization.
